# Jabil Brand Assets

Organized per [Jabil Brand Guidelines v24](../reference/jabil-brand-guidelines-v24.md) (September 2025).

## Directory Structure

```
brand-assets/
├── README.md                  ← This file
├── logos/
│   ├── digital/               ← RGB formats for screens (web, UI, presentations)
│   │   ├── svg/               ← Vector — preferred for web
│   │   ├── png/               ← Raster with transparency
│   │   └── jpg/               ← Raster without transparency
│   └── print/                 ← CMYK/Pantone formats for print
│       ├── cmyk/              ← CMYK ai/eps/pdf
│       └── pantone/           ← Pantone PMS ai/eps/pdf
├── fonts/
│   ├── roboto/                ← Primary typeface (all weights)
│   ├── roboto-condensed/      ← Condensed variant
│   ├── noto-sans-jp/          ← Japanese CJK support
│   └── noto-sans-sc/          ← Simplified Chinese CJK support
├── triangle-stream/
│   ├── digital/               ← RGB versions for screens
│   └── print/                 ← CMYK versions for print
├── tagline-lockups/           ← Logo + "Made Possible. Made Better."
│   ├── english/
│   ├── chinese/
│   └── spanish/
└── _inbox/                    ← Raw downloads (unorganized)
```

## Logo Usage Rules

- **Light backgrounds**: Jabil Blue text + Sky Blue arrow
- **Dark backgrounds**: White text + Sky Blue arrow (or all white)
- Minimum clear space = height of the "J" in the logo
- Never distort, recolor, add effects, or combine with other elements
- No division/sector-specific logos — use lockup format instead
